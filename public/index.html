The Git client for the age of AI agents.

Let agents write code and stay accountable for it. The agent proposes, you approve, and GitMaster records what really happened. Native, fast, and local-first.

Stacked branches · preview

Small branches that stay stacked.

Break a large change into a stack of reviewable branches. When the base moves, GitMaster shows exactly which ones fell behind and restacks them with an exact plan and an atomic undo.

  • Each branch has one parent; the sidebar shows the tree
  • Stale edges show up right in the history graph
  • Drag a branch onto another to set its parent
Agent threads

Find out why, weeks later.

Every Claude Code session becomes a searchable thread: what was asked, what changed, which files were edited. Stored inside your repository's .git, never in your working tree.

  • Search every prompt, reply and tool call
  • Open an agent's edit as a diff
  • Link a thread to the commit it produced
A complete Git client

Stage the exact lines you mean.

Working Copy, history graph, branches, worktrees, conflicts and a command palette, all without waiting for the UI. Stage per file, per chunk, per line, and keep track of what you have actually read.

  • Warns when half of a replacement is staged
  • Keyboard first: Ctrl+K reaches every action
  • Long lists stay smooth; nothing blocks while Git works
