Let agents write the code. Stay the one who approves it.

GitMaster is a fast Git client with a companion for your terminal. Your agent proposes, you review it line by line, and GitMaster keeps a record of what really happened.

It’s free, it’s open source, and it runs entirely on your machine.

Install it on Linux:

curl -fsSL https://gitmaster.dev/install.sh | sh

x86_64 and arm64. On macOS, build it from source. It only needs git. No account, no sign-up.

Review your agent’s code before it becomes a commit.

When an agent edits your code, you read it the way you’d read a colleague’s pull request. Except there’s no pull request: no push, no waiting for CI, nothing leaves your machine.

Select the lines you want changed and leave a comment. Your agent picks it up over MCP, fixes the code and answers. Then GitMaster shows you what the lines looked like before and after, measured from its own snapshots of your files. It doesn’t take the agent’s word for it. You decide whether to resolve the comment.

Find out why a line is the way it is, weeks later.

The reasoning behind agent-written code usually lives in a chat that’s gone by the time someone asks about it. GitMaster records each Claude Code session as a thread, stored inside your repository’s .git folder, and links it to the code it wrote.

Put your cursor on a line and ask where it came from. You get the commit, the session behind it, what was asked and what the agent answered. Your agent can search the same threads before it touches that code again.

Change several repositories as one.

Real changes rarely stay in one repository. A workspace puts a branch of each service side by side in one folder, for you and for your agent.

Nothing is cloned again. Each service in a workspace is a plain Git worktree of the clone you already have, so a commit made there is on your branch right away. When everything works together, commit the workspace to remember that exact combination.

Run agents side by side.

Give each agent its own branch in its own folder, so they never trip over each other or over you. The commands print plain paths, ready for your scripts, tmux or a key binding.

And a Git client you’ll want to use anyway.

Under all of this is a complete, native Git client. It doesn’t make you wait, even on large repositories.

  • Stage by file, by hunk or by line, and see when half a replacement is staged.
  • History as a commit graph, with the files and diff of every commit.
  • Branches, worktrees, fetch, pull and push, one click away.
  • Merge conflicts resolved inside the app (preview).
  • Quick Open and text search across the repository.
  • A command palette that reaches every action from the keyboard.
  • Stacked branches that restack when the base moves (preview).
  • Your own rules, as sandboxed Lua scripts that run when you choose.

Built to be trusted.

It only needs git. No server, no account, no extra tools to install.

It’s local. Your code, your history and your agent sessions stay on your machine.

It never touches your working tree. No config files dropped into your repositories, which matters when you can’t even edit a .gitignore.

It’s plain Git underneath. What you see is your repository, not a layer on top of it.

Free. Really.

GitMaster is open source under the Apache 2.0 license. It’s written in Rust and draws its own interface, so it starts instantly and stays fast. Read the code, build it, change it.
